A task manager that handles Arabic and English together

Many teams work in both languages. TaskHub lets one list hold Arabic and English tasks without flipped punctuation or broken alignment.

Direction follows the text

Titles, notes, checklist steps, comments and categories each pick their own direction from the first strong character. An Arabic title aligns right to left, and the English task below it stays left to right.

What this solves

  • Mixed lists, such as an English ticket title next to an Arabic page name, stay readable.
  • Checklists and comments keep correct punctuation.
  • Names in either script work for assigning and mentioning teammates.

Tips for bilingual SEO work

  • Create one category per site and language, such as a site name followed by the language.
  • Add a checklist step to confirm hreflang pairs point at each other.
  • Use the content brief template once per language rather than translating one brief.

Common questions

Is the TaskHub interface available in Arabic?

The interface is in English today. Task titles, notes, comments and categories can be in Arabic, English or both.

Can I mention or assign teammates with Arabic names?

Yes. Type @ followed by the first name in either script, for example @عمر or @sara, and TaskHub assigns the task.

Does the quick-add box understand Arabic dates?

Not yet. Type dates and times with English words such as tomorrow 5pm, or pick a date in the task window.

Can one task mix Arabic and English?

Yes. Direction is set from the first strong character of each field, so a mixed line still reads correctly.
