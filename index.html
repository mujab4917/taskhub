Questions people ask

Is TaskHub free?

Yes. TaskHub is free to use. You create an account, make a team or join one with an invite code, and start adding tasks.

Who can see my tasks?

Only you can see a task you create. A teammate sees it when you assign it to them, share it with them, or share it with the whole team. The database enforces these rules, so they apply on every screen, including reports and dashboards.

Can my manager see my private tasks?

No. The team owner has the same view as everyone else: they see only what is assigned or shared with them. One honest note: whoever administers the underlying database can technically access stored data, as with any hosted app.

Does TaskHub replace ClickUp or other project tools?

No. TaskHub is the personal and small-team layer next to your main tool. You can paste a ticket link into any task, copy a title and description in a format ClickUp accepts, and import tasks from a ClickUp CSV export.

Do reminders work when the app is closed?

Reminders appear while TaskHub is open, and a minimized window is fine. For reminders that work even when the app is closed, export your tasks to a calendar file. Your calendar app then handles the alarms.

Does TaskHub support Arabic?

Yes. Titles, notes and comments switch direction automatically, so Arabic and English tasks sit side by side in one list.

Can I install TaskHub like an app?

Yes. Open it in Chrome or Edge and choose Install. It gets its own window, a taskbar icon and can start with your computer. On phones, use Add to Home Screen.
