SEO task templates you can copy or use in TaskHub

Six checklists for the work SEO teams repeat most. Copy them anywhere, or start a task from them inside TaskHub with the steps already filled in.

Use them in TaskHub

SEO page audit checklist

Use this for one page or one template, such as a category or listing page. Finish with a short summary a developer or editor can act on.

  1. Title tag and meta description. Unique, describes the page, and fits without truncation.
  2. H1 and heading structure. One clear H1, with H2s that follow the page's real sections.
  3. Canonical and indexability. The canonical points to the right URL, and robots rules allow what should rank.
  4. Internal links in and out. Important pages link to it, and it links to related pages with descriptive anchors.
  5. Structured data. Markup matches the visible content and validates without errors.
  6. Page speed and Core Web Vitals. Check real-user data first, then lab tests for the cause.
  7. Mobile rendering. Content, links and buttons all work on a phone-sized screen.
  8. Summary. List findings by impact, with example URLs.

Content brief template

A good brief saves the writer a day of guessing. Fill the fields first, then work through the steps.

  1. Fields to fill: primary keyword, secondary keywords, search intent, market and language, competitor URLs.
  2. Keyword research in each language you publish, not a translation of one list.
  3. Review the top five results and note what they cover and what they miss.
  4. Outline and headings that answer the main question early.
  5. FAQ ideas taken from real searches and forum questions.
  6. Internal link targets to add from and to the new page.
  7. Meta title and description drafted before writing starts.
  8. Lead approval before the brief goes to the writer.

Dev ticket template for an SEO fix

Developers act faster on a ticket that shows the problem, the place and the finish line.

  1. Problem in one sentence.
  2. Where it happens: example URLs or the template name.
  3. Current behaviour with a screenshot or the exact text.
  4. Expected behaviour with the exact wording where it matters, such as a title pattern.
  5. Acceptance criteria a tester can check on the live page.
  6. Follow-up: verify on live and close the ticket.

Monthly SEO report checklist

Run it on the same day each month so trends are comparable.

  1. Pull Search Console data for the full month.
  2. Compare clicks and impressions with last month and the same month last year.
  3. Check rankings for the keywords you track.
  4. Note wins and losses, with a likely reason for each.
  5. List next month's actions with owners and dates.
  6. Send the report and log the follow-ups as tasks.

New landing page launch checklist

Run it before and after a page goes live.

  1. Confirm the target keyword and the final URL.
  2. Write the title, meta description and H1.
  3. Add schema markup that matches the content.
  4. Set canonical and index rules.
  5. Add internal links to the page from relevant pages.
  6. Add the page to the XML sitemap.
  7. Submit the URL for indexing in Search Console.
  8. Check impressions and rankings after one week.

Weekly sync prep

Fifteen minutes of preparation keeps the meeting short.

  1. Review last week's wins.
  2. List blockers and who can remove them.
  3. Prepare a rankings and traffic snapshot.
  4. Add agenda items.

Adapting these for Arabic and English sites

Run keyword research in each language, check that headings read naturally right to left, and confirm that hreflang pairs point at each other. TaskHub handles Arabic and English in the same task list. See Arabic support.

Common questions

How do I use these templates in TaskHub?

Create a new task and choose a template under Start from a template. The title, notes and checklist fill in, and you adjust them for the job.

Can I save my own template?

Yes. Open any task, choose More, then Save as a template. Your templates appear next to the ready-made ones.

How often should I run a page audit?

Run one when a template changes, before a major launch and on your highest-traffic pages each quarter. A monthly report checklist keeps the rest visible.

Are these checklists complete?

They cover the steps teams repeat most. Add steps for your own stack, and keep the order that suits your workflow.
